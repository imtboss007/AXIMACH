# AxiMach

AxiMach is a responsive manufacturing intelligence workspace for CNC/VMC operations, process planning, tooling, quality, and production visibility.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Product direction

- Futuristic, high-contrast industrial interface
- Responsive desktop and mobile layouts
- Scrollable machining process timeline
- Production, machine, tooling, quality, and job-work modules
- UI-first prototype data; connect real APIs and persistence in later phases
